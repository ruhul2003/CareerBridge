CareerBridge – Modern Job Platform
CareerBridge is a sleek, full-featured job marketplace connecting talented job seekers with top recruiters and companies. Built with a beautiful dark UI, smooth animations, and powerful backend.

Tech Stack

Frontend: Next.js 16 (App Router), React 19, Tailwind CSS
Authentication: Better Auth (Email + Google)
Database: MongoDB
Payments: Stripe
UI/Animations: HeroUI, Motion (Framer Motion), Lucide Icons
Other: React Hot Toast, ImgBB (for avatars)

Core Features

Role-based dashboards (Seeker & Recruiter)
Advanced job search & filters
Company management system
Subscription plans with Stripe integration
Profile management with avatar upload
Responsive dark-first design with premium feel

Dependencies Highlights

next, react, better-auth, @better-auth/mongo-adapter
mongodb, stripe, @stripe/stripe-js
lucide-react, motion, react-hot-toast, @heroui/react

How to Run Locally

Clone the repo
npm install
Create .env.local with your credentials (MongoDB, Google OAuth, Stripe)
npm run dev
Visit http://localhost:3000
